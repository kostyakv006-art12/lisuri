ПАПКА С ПЕСНЯМИ ДЛЯ ПЛЕЕРА

Сейчас здесь 8 демо-мелодий (созданы специально для сайта, без авторских прав): 1.mp3 … 8.mp3.

КАК ПОСТАВИТЬ СВОИ ПЕСНИ
1. Переименуй свою песню в номер: 1.mp3, 2.mp3 … и положи сюда с заменой.
   (подходят .mp3, .m4a, .ogg, .wav)
2. Открой script.js, найди  const tracks  и поменяй название и исполнителя:
   { title: "Perfect", artist: "Ed Sheeran", genre: "акустика", file: "1", ... }
3. Сохрани и обнови страницу (Ctrl+F5).

Больше песен — добавь файл 9.mp3 и строку с file: "9" в конец списка tracks.
Меньше песен — удали строку из tracks (файл можно оставить или удалить).
Можно не переименовывать файлы: file: "Ed Sheeran - Perfect" → ищет music/Ed Sheeran - Perfect.mp3
