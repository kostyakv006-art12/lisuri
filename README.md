# История бесконечной любви, которая идёт 10 месяцев

Романтический сайт-подарок 11.12.2025 — 11.10.2026. Работает без сборки и без сервера:
просто открой `index.html` в браузере (лучше Chrome / Safari / Edge).

## Что внутри
```
index.html   — разметка всех секций
style.css    — дизайн (палитра, шрифты, анимации, мобильная версия)
script.js    — ВСЕ ТЕКСТЫ И НАСТРОЙКИ в самом верху + логика
assets/      — фоны (задний фон / фон 2 / фон 3), курсор
music/       — песни для плеера: 1.mp3 … 8.mp3 (сейчас демо-мелодии)
player.js / player.css — музыкальный плеер (редактировать не нужно)
photos/      — фото 1…10, «и 9» (.webp для сайта + .jpg для Telegram-бота)
videos/      — видео 1…9 и «последнее»
```

## Секции (сверху вниз)
1. **Hero** — название, счётчик «мы вместе уже…», кнопка «Листать».
2. **Наша история** — таймлайн: фото N + видео N, иконка-значок на линии.
3. **Секретные записки** — 14 карточек (стикер / салфетка / сердечко / свиток), переворачиваются по нажатию.
4. **Галерея** — сетка поляроидов + видео; клик открывает просмотр на весь экран.
5. **Наш плейлист** — песни играют прямо на сайте, по очереди; сверху появляется плеер
   (перемотка, громкость, назад/вперёд; на первой песне «назад» выключено, на последней — «вперёд»).
6. **Скоро снова праздник** — обратный отсчёт до следующей годовщины.
7. **Скажи что-то важное** — кнопка, из «конверта» выпадает случайная записка.
8. **Финал** — последнее видео и письмо. Затем минимальный футер.

## Где что менять (всё в начале `script.js`)
| Что | Переменная |
|---|---|
| Подписи к фото и иконки на таймлайне | `photos` (`caption`, `icon`), `collage` |
| Подписи к видео | `videos` |
| Даты под фото/видео | поле `date` — сейчас пустое (так задумано). Впишешь — появится |
| Тексты записок | `notes` (`icon`, `text`), стили — `NOTE_STYLES` |
| Фразы кнопки «Скажи что-то важное» | `importantMessages` |
| Песни плеера | `tracks` (`title`, `artist`, `genre`, `file`, `icon`) + файлы в `music/` |
| Дата обратного отсчёта | `COUNTDOWN` |
| Фоны и их порядок | `backgrounds` (файлы в `assets/`) |

Пустые подписи просто не показываются.

## Как устроен фон (почему нет швов)
Фон — это не картинка внутри страницы, а отдельный слой `position: fixed` ровно на весь экран
(`.bg` в index.html). Поэтому он физически не может «закончиться» при прокрутке и не даёт шва.
Три фона лежат друг над другом, и `script.js → setupBackground()` по проценту прокрутки
плавно меняет их прозрачность (кроссфейд): вверху — фон 1, в середине — фон 2, внизу — фон 3.
Меняется только `opacity`, это самая дешёвая анимация для видеокарты — работает плавно и на iPhone
(где `background-attachment: fixed` не поддерживается). Тексты лежат на светлых карточках —
читаются на любом участке фона.

Чтобы заменить фон — положи свою картинку в `assets/` под тем же именем
(или впиши новое имя в `backgrounds`). Подойдёт любой размер ~1600×900 и больше.

## Как открыть / задеплоить
- Локально: двойной клик по `index.html`.
- В интернете бесплатно: перетащи папку на https://app.netlify.com/drop — получишь ссылку.

## Доступность и скорость
- Фото в WebP, грузятся лениво (по мере прокрутки), видео — только при показе.
- Если в системе включено «уменьшить движение», анимации и лепестки отключаются.
- Записки и кнопки работают с клавиатуры (Tab + Enter), у картинок есть alt.

Telegram-бот из соседней папки продолжает работать с этим сайтом: он читает те же подписи
из `script.js` и отправляет `.jpg`-версии фото.

## Как поставить свои песни
1. Переименуй свои песни в `1.mp3`, `2.mp3` … и положи в папку `music/` с заменой демо-файлов.
2. В `script.js` найди `const tracks` и поменяй `title` (название) и `artist` (исполнитель).
   `file: "1"` — это и есть файл `music/1.mp3`.
3. Сохрани и обнови страницу (Ctrl+F5).

Подробнее — в `music/README.txt`.
